# Portail Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build « Portail », a Next.js page at `https://payoux.net` behind Authentik OIDC that lists household services filtered by Authentik group and dims LAN-only services when the visitor comes from the internet.

**Architecture:** One Next.js 16 App Router app. Pure logic (`lib/origin.ts`, `lib/visibility.ts`, `lib/search.ts`, `lib/user.ts`, `lib/icons.ts`) has no Next.js imports and is unit-tested with Vitest. `lib/services.ts` is the only reader of `services.yml`. The server page filters by group before rendering; the client component only searches what it received. Auth.js v5 handles OIDC; a development-only fake user replaces it locally and in Playwright.

**Tech Stack:** Next.js 16.4, React 19.3, TypeScript 7, Auth.js v5 (`next-auth@beta`), Tailwind 4.3, shadcn/ui on Base UI (`@base-ui/react` 1.9), `yaml` 2, `zod` 4, Vitest 5, Playwright 1.64, Docker (`node:24-alpine`), GitHub Actions, GHCR.

**Spec:** `docs/superpowers/specs/2026-10-11-portail-design.md`

## Global Constraints

- All UI text in French; `<html lang="fr">`; page title « Portail ».
- `services.yml` format: `sections` (ordered, unique) + `services[]` with `name`, `url`, `icon` (slug `^[a-z0-9-]+$`), `section`, `description`, `groups` (non-empty), `reach` (`everywhere` | `lan`).
- Env: `SERVICES_FILE` (default `/data/services.yml`), `ICONS_DIR` (default `/data/icons`), `AUTH_SECRET`, `AUTH_AUTHENTIK_ID`, `AUTH_AUTHENTIK_SECRET`, `AUTH_AUTHENTIK_ISSUER=https://auth.payoux.net/application/o/portail/`, `AUTH_URL=https://payoux.net`, `AUTH_TRUST_HOST=true`.
- Admin group name: `authentik Admins` (constant `ADMIN_GROUP`).
- Origin header: `X-Portal-Origin`; only the exact value `internet` means internet, anything else (or missing) means `lan`. Never read `X-Forwarded-For`.
- Dimmed card: `opacity-40` + « À la maison uniquement »; link stays active.
- End-session URL: `https://auth.payoux.net/application/o/portail/end-session/`.
- Icon source: `https://cdn.jsdelivr.net/gh/homarr-labs/dashboard-icons/png/<slug>.png`; PNG signature `89 50 4E 47 0D 0A 1A 0A`.
- Icon responses: `Content-Type: image/png`, `Cache-Control: private, max-age=86400`; bad name 400, missing 404.
- Image: `ghcr.io/rykian/portail`, tags `latest` and `sha-<short>`; runs as user `node` on port 3000; no secrets and no `services.yml` in the image.
- The real `services.yml` is never committed (`/data/` is git-ignored).
- Dev fake user only when `NODE_ENV === 'development'`.

**Two refinements of the spec, decided while planning:**

1. Sign-in redirect goes to `/login` (a route handler calling Auth.js `signIn("authentik")`), not `/api/auth/signin/authentik`: Auth.js v5 only starts an OAuth flow from a POST on that URL, while `signIn()` on the server works from a plain GET.
2. In development only, the fake user's groups can be overridden per request with header `x-dev-user-groups` (in addition to `DEV_USER_GROUPS`). Playwright needs two users against one `next dev` server; production ignores the header.

## Review Focus

1. Search query made only of spaces → treated as empty, everything shown (test in Task 5).
2. Authentik token without a `groups` claim (scope mapping missing) → user has no groups and sees « Aucun service pour l’instant. », no crash (tests in Tasks 4 and 7).
3. Typing `/` inside the search field → a slash is typed, focus is not hijacked (test in Task 9).
4. `services.yml` deleted or unreadable after a good load (e.g. a `mv` during an edit) → last good list keeps being served (test in Task 3).
5. An icon that fails to load before React hydrates (missed `onError`) → the initial tile still appears (test in Task 9).

`lib/origin.ts`:

```ts
export type Origin = "lan" | "internet";

export function parseOrigin(value: string | null | undefined): Origin {
  return value === "internet" ? "internet" : "lan";
}

export function resolveOrigin(
  header: string | null,
  env: { NODE_ENV?: string; DEV_ORIGIN?: string },
): Origin {
  if (header === null && env.NODE_ENV === "development") {
    return parseOrigin(env.DEV_ORIGIN);
  }
  return parseOrigin(header);
}
```

`lib/services.ts`:

```ts
import { readFile, stat } from "node:fs/promises";
import { parse } from "yaml";
import { z } from "zod";

const serviceSchema = z.object({
  name: z.string().min(1),
  url: z.url(),
  icon: z.string().regex(/^[a-z0-9-]+$/),
  section: z.string().min(1),
  description: z.string().min(1),
  groups: z.array(z.string().min(1)).min(1),
  reach: z.enum(["everywhere", "lan"]),
});

export const configSchema = z
  .object({
    sections: z
      .array(z.string().min(1))
      .min(1)
      .refine((sections) => new Set(sections).size === sections.length, "sections must be unique"),
    services: z.array(serviceSchema),
  })
  .superRefine((config, ctx) => {
    config.services.forEach((service, index) => {
      if (!config.sections.includes(service.section)) {
        ctx.addIssue({
          code: "custom",
          path: ["services", index, "section"],
          message: `unknown section "${service.section}"`,
        });
      }
    });
  });

export type Config = z.infer<typeof configSchema>;
export type Service = Config["services"][number];

export function parseConfig(text: string): Config {
  return configSchema.parse(parse(text));
}

export function createServiceLoader(path: string): () => Promise<Config> {
  let cached: { mtimeMs: number; config: Config } | null = null;

  return async function load() {
    try {
      const { mtimeMs } = await stat(path);
      if (cached && cached.mtimeMs === mtimeMs) return cached.config;
      const config = parseConfig(await readFile(path, "utf8"));
      cached = { mtimeMs, config };
      return config;
    } catch (error) {
      if (!cached) throw error;
      console.error(`[services] ${path} unusable, keeping the last good version:`, error);
      return cached.config;
    }
  };
}

let defaultLoader: (() => Promise<Config>) | null = null;

export function loadServices(): Promise<Config> {
  defaultLoader ??= createServiceLoader(process.env.SERVICES_FILE ?? "/data/services.yml");
  return defaultLoader();
}
```

```ts
import type { Origin } from "./origin";
import type { Config } from "./services";

export const ADMIN_GROUP = "authentik Admins";

export type VisibleService = {
  name: string;
  url: string;
  icon: string;
  description: string;
  section: string;
  dimmed: boolean;
};

export type VisibleSection = { name: string; services: VisibleService[] };

export function visibleSections(config: Config, groups: string[], origin: Origin): VisibleSection[] {
  return config.sections
    .map((name) => ({
      name,
      services: config.services
        .filter((s) => s.section === name && s.groups.some((g) => groups.includes(g)))
        .map((s) => ({
          name: s.name,
          url: s.url,
          icon: s.icon,
          description: s.description,
          section: s.section,
          dimmed: s.reach === "lan" && origin === "internet",
        })),
    }))
    .filter((section) => section.services.length > 0);
}

export function isAdmin(groups: string[]): boolean {
  return groups.includes(ADMIN_GROUP);
}
```

```ts
import type { VisibleSection, VisibleService } from "./visibility";

export function normalize(s: string): string {
  return s.normalize("NFD").replace(/\p{Diacritic}/gu, "").toLowerCase();
}

export function matches(service: VisibleService, query: string): boolean {
  const q = normalize(query.trim());
  if (!q) return true;
  return [service.name, service.description, service.section].some((field) => normalize(field).includes(q));
}

export function filterSections(sections: VisibleSection[], query: string): VisibleSection[] {
  return sections
    .map((section) => ({ ...section, services: section.services.filter((s) => matches(s, query)) }))
    .filter((section) => section.services.length > 0);
}
```

```ts
export type PortalUser = { name: string; email: string; image: string | null; groups: string[] };

export function devUser(
  env: { NODE_ENV?: string; DEV_USER_GROUPS?: string },
  groupsHeader: string | null = null,
): PortalUser | null {
  if (env.NODE_ENV !== "development") return null;
  const raw = groupsHeader ?? env.DEV_USER_GROUPS;
  if (!raw) return null;
  return {
    name: "Dev",
    email: "dev@localhost",
    image: null,
    groups: raw.split(",").map((g) => g.trim()).filter(Boolean),
  };
}

export function groupsFromProfile(profile: Record<string, unknown> | undefined): string[] {
  const groups = profile?.groups;
  return Array.isArray(groups) ? groups.filter((g): g is string => typeof g === "string") : [];
}

export function initials(name: string): string {
  const words = name.trim().split(/\s+/).filter(Boolean);
  if (words.length === 0) return "?";
  const letters = words.length === 1 ? words[0].slice(0, 2) : words[0][0] + words[words.length - 1][0];
  return letters.toUpperCase();
}
```

```ts
  callbacks: {

      if (profile) token.groups = groupsFromProfile(profile);

    image: session.user.image ?? null,
```

```tsx
"use client";

import { useEffect, useRef, useState } from "react";
import { Input } from "@/components/ui/input";
import { filterSections } from "@/lib/search";
import type { PortalUser } from "@/lib/user";
import type { VisibleSection } from "@/lib/visibility";
import { ServiceCard } from "./service-card";
import { UserMenu } from "./user-menu";

function isTyping(target: EventTarget | null): boolean {
  return (
    target instanceof HTMLElement &&
    (target.tagName === "INPUT" || target.tagName === "TEXTAREA" || target.isContentEditable)
  );
}

export function Portal({ sections, user, admin }: { sections: VisibleSection[]; user: PortalUser; admin: boolean }) {
  const [query, setQuery] = useState("");
  const search = useRef<HTMLInputElement>(null);
  const shown = filterSections(sections, query);

  useEffect(() => {
    function onKeyDown(event: KeyboardEvent) {
      if (event.key !== "/" || event.metaKey || event.ctrlKey || event.altKey || isTyping(event.target)) return;
      event.preventDefault();
      search.current?.focus();
    }
    window.addEventListener("keydown", onKeyDown);
    return () => window.removeEventListener("keydown", onKeyDown);
  }, []);

  function onSearchKeyDown(event: React.KeyboardEvent<HTMLInputElement>) {
    if (event.key === "Escape") {
      setQuery("");
      event.currentTarget.blur();
    }
    if (event.key === "Enter") {
      const first = shown[0]?.services[0];
      if (first) window.location.href = first.url;
    }
  }

  return (
    <div className="mx-auto max-w-6xl px-4 py-6">
      <header className="mb-8 flex items-center gap-4">
        <h1 className="text-2xl font-semibold">Portail</h1>
        <Input
          ref={search}
          type="search"
          value={query}
          onChange={(event) => setQuery(event.target.value)}
          onKeyDown={onSearchKeyDown}
          placeholder="Rechercher… (/)"
          aria-label="Rechercher"
          className="ml-auto max-w-sm"
        />
        <UserMenu user={user} admin={admin} />
      </header>

      {sections.length === 0 ? (
        <p>Aucun service pour l’instant.</p>
      ) : shown.length === 0 ? (
        <p>Aucun résultat pour « {query} »</p>
      ) : (
        shown.map((section) => (
          <section key={section.name} className="mb-8">
            <h2 className="mb-3 text-lg font-medium">{section.name}</h2>
            <ul className="grid grid-cols-1 gap-3 sm:grid-cols-2 lg:grid-cols-3 xl:grid-cols-4">
              {section.services.map((service) => (
                <li key={service.name}>
                  <ServiceCard service={service} />
                </li>
              ))}
            </ul>
          </section>
        ))
      )}
    </div>
  );
}
```

- [ ] **Step 3: Implement**

`scripts/fetch-icons.mjs`:

```js
import { access, readFile, writeFile } from "node:fs/promises";
import path from "node:path";
import { pathToFileURL } from "node:url";
import { parse } from "yaml";

const SOURCE = "https://cdn.jsdelivr.net/gh/homarr-labs/dashboard-icons/png";
const PNG_SIGNATURE = [0x89, 0x50, 0x4e, 0x47, 0x0d, 0x0a, 0x1a, 0x0a];

export function isPng(bytes) {
  return bytes.length >= PNG_SIGNATURE.length && PNG_SIGNATURE.every((byte, i) => bytes[i] === byte);
}

export function iconSlugs(config) {
  const icons = (config?.services ?? []).map((service) => service?.icon);
  return [...new Set(icons.filter((icon) => typeof icon === "string" && /^[a-z0-9-]+$/.test(icon)))];
}

async function exists(file) {
  try {
    await access(file);
    return true;
  } catch {
    return false;
  }
}

async function main() {
  const servicesFile = process.env.SERVICES_FILE ?? "/data/services.yml";
  const iconsDir = process.env.ICONS_DIR ?? "/data/icons";
  const slugs = iconSlugs(parse(await readFile(servicesFile, "utf8")));
  const result = { downloaded: [], skipped: [], failed: [] };

  for (const slug of slugs) {
    const file = path.join(iconsDir, `${slug}.png`);
    if (await exists(file)) {
      result.skipped.push(slug);
      continue;
    }
    try {
      const response = await fetch(`${SOURCE}/${slug}.png`);
      const bytes = new Uint8Array(await response.arrayBuffer());
      if (!response.ok || !isPng(bytes)) throw new Error(`HTTP ${response.status}`);
      await writeFile(file, bytes);
      result.downloaded.push(slug);
    } catch {
      result.failed.push(slug);
    }
  }

  for (const [label, list] of Object.entries(result)) {
    console.log(`${label}: ${list.length ? list.join(", ") : "-"}`);
  }
}

if (process.argv[1] && import.meta.url === pathToFileURL(process.argv[1]).href) {
  await main();
}
```
